# Minecraft JS 复刻版 v5.0 (完整 3x3 交互式合成系统 + 熔炉烧炼台 + 80 种原版方块/物品 + 6 阶段生存通关版)基于 <strong>Three.js (r128)</strong> 与原生 ES6 模块化架构构建的 Minecraft JS 复刻版 v5.0：- <strong>原版 16x16 材质贴图双引擎 (`js/textures.js`)</strong>：  1. 零延迟内嵌 <strong>80 种</strong> 像素级还原方块、全材质工具武器、矿锭、原材料与食物精灵（43 种 3D 可放置方块 + 37 种原版工具/武器/矿产/食物）；  2. 异步从 `PrismarineJS/minecraft-assets` 与 `InventivetalentDev/minecraft-assets` 官方材质库热加载 16x16 原版 PNG 贴图（自动应用草方块与树叶原版群系绿色滤镜染色）。- <strong>完整 3x3 交互式合成系统 + 35 种原版配方 + 交互式熔炉烧炼台 (`js/main.js`)</strong>：  1. <strong>亲手摆格合成 (`Interactive 3x3 Crafting Grid`)</strong>：支持在 80 种物品库选取任意原料（如橡木原木、橡木木板、木棍、圆石、铁锭、金锭、钻石、燧石、火药、烈焰棒、烈焰粉、末影珍珠、小麦、红苹果），在 3x3 合成格中亲手点击摆放图案（支持任意平移与水平镜像对称的 <strong>有序配方 Shaped Recipes</strong> 以及任意位置摆放的 <strong>无序配方 Shapeless Recipes</strong>）实时匹配合成结果；  2. <strong>分类检索配方书 (`Categorized Recipe Book`)</strong>：按「全部」「工具武器」「方块建材」「材料通关」「食物」分类展示 35 种原版配方，点击即可自动在 3x3 网格排布原料并合成装备；  3. <strong>交互式熔炉烧炼台 (`Interactive Furnace Smelting Station`)</strong>：支持装填原料（铁矿石➔铁锭、金矿石➔金锭、沙子➔玻璃、圆石➔石头、原木➔木炭、烤熟猪排）与燃料（煤炭/原木/木板/熔岩桶）。- <strong>全套 80 种原版方块与物品体系</strong>：  - <strong>五阶全系工具与武器</strong>：木镐/石镐/铁镐/金镐/钻石镐、木剑/石剑/铁剑/金剑/钻石剑、木斧/石斧/铁斧/钻石斧、铁锹/钻石锹、打火石、空铁桶/水桶/熔岩桶；  - <strong>核心合成材料与功能方块</strong>：木棍、煤炭、铁锭、金锭、钻石、燧石、火药、烈焰棒、烈焰粉、末影珍珠、末影之眼、书本、储物箱、书架、火把、钻石块、铁块、金块；  - <strong>生存食物与恢复</strong>：小麦、红苹果、面包、附魔金苹果、熟猪排（手持右键食用可恢复生命与饱食度）。
